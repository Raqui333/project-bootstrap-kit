# Registro de Decisões (ADR)

Índice de decisões técnicas e arquiteturais registradas neste projeto. Ver
`docs/decisions/TEMPLATE.md` para o formato usado em cada arquivo.

Esta pasta explica **por que** o sistema é como é (motivação, trade-offs,
alternativas descartadas) — diferente de `docs/architecture/`, que explica
**como** ele funciona.

| # | Título | Status |
| --- | --- | --- |
| [0001](./0001-<slug>.md) | `<Título curto e afirmativo>` | `<Proposta / Aceita / Superada por NNNN>` |

Numeração é cronológica (ordem em que a decisão foi de fato registrada), não a
ordem de fases/épicos do roadmap — decisões antecipadas em uma task futura
entram com o próximo número sequencial disponível **no momento em que forem de
fato registradas**, não com um número reservado antecipadamente.
