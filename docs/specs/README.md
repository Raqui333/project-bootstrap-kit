# SPECs

Uma SPEC descreve **como** implementar o que um RFC aceito decidiu
(`docs/rfcs/`), em detalhe suficiente para virar tasks (`tasks/TEMPLATE.md`).
Ela não reabre decisões do RFC. Criar com a skill `criar-spec`; molde em
[TEMPLATE.md](./TEMPLATE.md) (Parte A: problema e requisitos; Parte B:
especificação técnica, seções 1–14; Parte C: qualidade e análise, seções 15–20;
regras de escrita no topo).

## Numeração

A SPEC leva o **mesmo número do RFC** que detalha (SPEC 0007 detalha o RFC 0007).

## Quando existe SPEC

Só para RFC **aceito**. RFC pequeno cujo "Plano em alto nível" já basta para
virar tasks pode dispensar a SPEC — dizer isso no RFC.
